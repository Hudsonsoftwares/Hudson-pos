Hudson Rental Management

Complete Rental Solution for Odoo 19

Manage product rentals, pricing, scheduling, and invoicing from one powerful module

Overview

Hudson Rental Management provides a comprehensive solution for businesses that rent products to customers. From online booking to return processing and invoicing, manage your entire rental operation efficiently.

Key Features

🛒 Online Rental Booking

  • Customers can browse and rent products directly from your website
  • Real-time availability checking
  • Flexible date and time selection
  • Add to cart and checkout integration

💰 Flexible Pricing

  • Define pricing by hour, day, week, or month
  • Multiple pricing tiers per product
  • Automatic price calculation based on rental duration
  • Support for late fees and security deposits

📦 Complete Order Management

  • Full rental lifecycle: quotation → confirmed → reserved → picked up → returned → done
  • Pickup and return wizards for easy processing
  • Extend rental periods while in progress
  • Track actual vs expected return dates

📊 Stock Integration

  • Real-time rental stock availability tracking
  • Automatic delivery order creation
  • Return processing with stock movements
  • Dedicated rental locations

💳 Invoicing & Payments

  • Generate invoices from rental orders
  • Automatic late fee calculation
  • Security deposit management
  • Integration with Odoo Accounting

👥 Customer Portal

  • Customers can view their rental history
  • Track current rental status
  • Request rental extensions
  • Access rental documents

📈 Reports & Analytics

  • Comprehensive rental analysis reports
  • Pivot and graph views
  • Track revenue by product, customer, period
  • Monitor rental performance

Configuration

  1. Go to Settings → Rental
  2. Configure rental location and picking type
  3. Set late fee and deposit products
  4. Mark products as rentable in Rental → Configuration → Rental Products
  5. Define pricing rules for each rental product

Usage

  1. Create Rental Orders: Rental → Orders → Create
  2. Add Rental Products: Select products marked as rentable
  3. Set Dates: Choose pickup and return dates
  4. Process Order: Confirm → Reserve → Pickup → Return → Invoice
