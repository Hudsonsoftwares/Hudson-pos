DESCRIPTION
-----------
Complete rental management solution for Odoo 19 with online booking,
flexible pricing, stock integration, and comprehensive reporting.

KEY FEATURES
------------
✓ Online rental booking through website
✓ Flexible pricing (hourly, daily, weekly, monthly)
✓ Complete order lifecycle management
✓ Real-time stock availability
✓ Customer portal access
✓ Automatic invoicing with late fees
✓ Security deposit management
✓ Rental extensions
✓ Comprehensive analytics
✓ Multi-company support

DEPENDENCIES
------------
Required Odoo Modules:
- base
- web
- sale_management
- stock
- product
- account
- portal
- website_sale

INSTALLATION
------------
1. Copy hudson_rental folder to Odoo addons directory
2. Restart Odoo service
3. Update Apps List
4. Install "Hudson Rental Management"
5. Configure settings

See INSTALL.md for detailed instructions.

QUICK START
-----------
1. Go to Settings → Rental → Configure locations
2. Create rental product with "Can be Rented" checked
3. Add pricing rules (duration + price)
4. Create rental order
5. Process: Confirm → Reserve → Pickup → Return → Invoice

See QUICKSTART.md for 5-minute setup guide.

confirmed   → Customer confirmed
reserved    → Stock reserved
picked_up   → Customer has items
returned    → Items returned
done        → Order completed & invoiced
cancel      → Order cancelled

PRICING CONFIGURATION
---------------------
Define multiple pricing tiers per product:
- Duration: Number (e.g., 1, 7, 30)
- Unit: hour/day/week/month
- Price: Amount in company currency

Example:
  1 day   = $50   ($50/day)
  7 days  = $300  ($42.86/day - Save 15%)
  30 days = $1000 ($33.33/day - Save 33%)

SECURITY GROUPS
---------------
Rental User    - Create and manage rental orders
Rental Manager - Full access + configuration

ACCESS RULES
------------
- Multi-company: Users see only their company data
- Portal: Customers see only their rental orders
- Public: Can browse rental products on website

WEBSITE ROUTES
--------------
/rental/products              - List all rental products
/rental/product/<id>          - Product detail + configurator
/rental/configure             - AJAX price calculation
/rental/add_to_cart           - Add rental to cart
/rental/check_availability    - Check product availability
/my/rentals                   - Customer portal list
/my/rentals/<id>              - Rental order detail

CONFIGURATION SETTINGS
----------------------
Settings → Rental:
- Rental Location           - Where rental stock is stored
- Rental Picking Type       - Delivery operation type
- Late Fee Product          - Product for late fees
- Deposit Product           - Product for deposits
- Auto Create Invoice       - Auto-invoice on return
- Require Security Deposit  - Mandate deposits
